🧱 Client Lifecycle Phase Decomposition

Time spent across Initialize, Prepare, Execute, Collect, and Cleanup

ℹ️ Understanding Lifecycle Phases: Separate phase medians do not sum to a measured median total. Unavailable phases are displayed as zero-length bars, not certified zero cost/time.
  • Initialize: Network handshake, authentication, and remote sandbox container allocation.
  • Prepare: Uploading test fixtures, writing input scripts, or provisioning environment variables.
  • Execute: Client-observed execute phase, including adapter/transport overhead; separate guest timing is available for some workloads.
  • Collect: Downloading generated output files, plots, database artifacts, and stdout streams.
  • Cleanup: Graceful container termination, disk unmounting, and session release.
